## 1. 交付变更总览

### 新增模块

- [`skills/agy-codex/scripts/runtime.py`](../skills/agy-codex/scripts/runtime.py)：共享执行内核（纯 Python 标准库）
  - 抽取原 `controller.py` 的公共底座：`WorkflowError`、`Interrupted`、`now`、`encode`、`_metadata_io`、`atomic_json`、`read_json`、`git`、`resolve_codex`、`pid_alive`、`stop_process`、`launch_gate`、`WindowsJob`、`worktree_lock`、`EventSummary`、`codex_settings`、`configured_codex`、`codex_exec_flags`、`run_process` 与 `_child-gate` 入口。
  - **统一工作区解析（Git 与非 Git）**：Git 仓库复用 `<gitdir>/superagent/` 与原 `worktree.lock`；非 Git 目录按 `os.path.normcase(resolve(cwd))` 哈希至 `~/.gemini/config/agy-codex/workspaces/<hash16>/`（支持 `AGY_CODEX_STATE_DIR`），不污染用户交付目录，不执行 `git init`。
  - **原子单写入互斥（`acquire_writer_lease`）**：通过短持有全局登记锁 `registry.lock` 原子完成“路径分量祖先/后代重叠检查 → 获取工作区锁 → 核查活跃 Strict Ticket/Plan 占用 → 登记所有权”，执行期间释放登记锁；异常残留清理要求同时满足“同主机 PID 不存活 + 对应工作区锁非阻塞可获取”；`sandbox="read-only"` 跳过写入锁不阻塞写任务。
  - **单一执行与恢复内核（`execute_run` / `reconcile_run`）**：以 `Run`（`runs/<run_id>/run.json`）作为运行事实来源；`resolve_resume` 支持 `RUN_ID` / 原生 `THREAD_ID` / 工作区 `last`，禁止跳过未对账的 `running`/`unknown` 后继 Run，保留同主机/`CODEX_HOME`/Provider 约束；对账不盲目重发。
