严格遵循“只减负、不扩展 Strict 管控职责”的原则，完成以下改动：

- [install.py](../install.py) 整体复制 `agents/` 目录，测试已验证 `--project` 安装自动包含 `agents/agy-codex-reviewer.md`。

- [references/review.md](../skills/agy-codex/references/review.md)：补充认知独立取证顺序要求。

### 2. Strict 热路径减负（Preflight 与全仓 Snapshot）
- **轻量 Preflight**（[agy_adapter.py](../skills/agy-codex/scripts/agy_adapter.py) `_fast_preflight`）：不再在每次 Strict Ticket 启动时调用 4 个 `codex` 子进程的完整 `doctor()`（实测 ~912 ms），改为仅检查 Codex launcher 解析与工作区/`CODEX_HOME` 写权限（~1 ms）；需要完整诊断时仍可通过 `options["full_preflight"]=True` 或 `user_cli.py doctor` 触发。
- **冗余全仓 Snapshot 裁剪**（[controller.py](../skills/agy-codex/scripts/controller.py)、[agy_adapter.py](../skills/agy-codex/scripts/agy_adapter.py)、[runtime.py](../skills/agy-codex/scripts/runtime.py)）：
  - `create()`：当显式路径集合与上一步不同，在内存中从当次 `snap` 投影 `previous_paths` 视图（通过 `git check-ignore --stdin -z` 识别新增显式忽略文件），不再重扫全仓；同时因 `_capture_files` 已在持 `worktree_lock` 下逐文件校验 SHA-256，移除复制后的冗余二次全仓扫描。`create()` 全仓扫描次数由 **2–3 次降至 1 次**。
  - `_prepare_review()`：移除 `_task_diff()` 之后的第 3 次全仓扫描；当 `permission_blocked` 跳过测试时直接复用 `before` 快照。
  - `agy_adapter._run_ticket()`：`c.run()` 刚转入 `REVIEW` 当轮直接读取刚生成的 `review-packet.json`，跳过紧接着的冗余 `c.packet()` 重算（恢复已有 `REVIEW` 以及 `c.verdict()` 内防越权写校验完整保留）。
  - **实测总扫描次数**：单轮 Strict Ticket（`create` → `run` → `review` → `verdict`）全仓 SHA-256 扫描由 **8–9 次降至 5 次**，且所有只读违约/外部篡改测试全部通过。

### 3. `models` 目录 TTL 缓存（基于实测收益落地）
- [routing.py](../skills/agy-codex/scripts/routing.py) 与 [user_cli.py](../skills/agy-codex/scripts/user_cli.py) 实现轻量 TTL 缓存（含 rate limits 时 TTL=120s，否则 600s），缓存键覆盖 `CODEX_HOME`、`$CODEX_HOME/config.toml` 的 `mtime_ns/size`、launcher、routing 配置及 `include_rates`，支持 `user_cli.py models --refresh` 强制刷新。
- **本机实测延迟**（隔离临时工作区，真实 `codex app-server`）：
  - 首次未命中（`from_cache=False`，10 models）：**2,502.8 ms**
  - 命中缓存（`from_cache=True`，含 Python 进程启动）：**242.0 ms**（**提速 >10x**）
  - 显式 `--refresh`（`from_cache=False`）：**1,813.9 ms**

### 4. CLI 易用性补强
- [user_cli.py](../skills/agy-codex/scripts/user_cli.py) 为 `inbox` 子命令补充 `--message` / `--text` 参数别名（兼容位置参数写法），修复实测中以 `--message` 方式发送实时 `steer` 时的参数解析问题。

### 5. 静态 Reviewer 宿主注册状态说明
- `agents/agy-codex-reviewer.md` 已按插件原生格式落地并通过 `install.py` 安装校验；Antigravity Desktop 是否在重启后自动将插件内静态 `agents/*.md` 注册为 `run_workflow` 可调用的 `type_name` 仍依赖宿主 UI 实际加载。若未自动注册，[agy_adapter.py](../skills/agy-codex/scripts/agy_adapter.py) 已提供 `reviewer_type` 配置与优雅降级（保留 `REVIEW` 证据，不重跑 Worker），结合切片 0 已验证的动态 `define_subagent` 只读子代理即可无缝运行。
